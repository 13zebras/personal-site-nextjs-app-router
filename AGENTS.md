# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Commands

```bash
# Development
pnpm dev          # Start the Vite dev server (runs the app in workerd)
pnpm build        # Build the Worker and client assets into dist/, then prerender every page to dist/client/*.html
pnpm preview      # Preview the production build locally
pnpm deploy       # Build and deploy with wrangler
pnpm typecheck    # Type-check with tsgo (TypeScript 7)

# Linting and Formatting (OXC)
pnpm lint         # Run oxlint
pnpm lint:fix     # Run oxlint with auto-fix
pnpm format       # Format code with oxfmt
pnpm format:check # Check code formatting
pnpm check        # Run lint + format check + typecheck
pnpm fix          # Run lint:fix + format
```

## Architecture

This is a portfolio website built with React 19, TypeScript 7 (tsgo), and TailwindCSS.

**Migration in progress:** moving from Next.js 16 (Railway) to TanStack Start on Cloudflare Workers. Work happens on step branches merged into `migrate/cloudflare`; `main` still deploys the Next.js site to Railway. `vite.config.ts` and `wrangler.jsonc` are at the root. Every page is prerendered at build time; the build starts a local workerd preview server to do it, so it needs to bind a local port.

### Project Structure

- `src/routes/` - TanStack Start file routes (`__root.tsx` shell, home, about, contact, portfolio, experience)
- `src/routes/api/contact.ts` - Contact form server route: verifies Turnstile, sends through Resend
- `src/router.tsx` - Router setup; `src/routeTree.gen.ts` is generated by the Vite plugin (don't edit)
- `public/` - Static files served as-is (favicon)
- `src/components/` - React components (Header, Footer, Hero, Portfolio, etc.)
- `src/styles/` - CSS files (globals.css + page-specific styles)
- `src/types/allTypes.ts` - Shared TypeScript interfaces
- `src/utils/` - Data files (projects.ts, work.ts) and utilities

### Key Integrations

- **Images**: static WebP files in `public/images/portfolio/`, referenced through `src/utils/images.ts`
- **Contact Form**: Resend (sent from `contact@mail.13z.dev`, visitor in `replyTo`) + Cloudflare Turnstile captcha
- **Animations**: react-simple-typewriter for typing effects

### Images

Each image in `public/images/portfolio/` has a full-size `<key>.webp` and a 24px `<key>-blur.webp` placeholder. Project images also have a 520px `<key>-card.webp`. To add a project image (ImageMagick), set `imageKey` in `projects.ts` and run:

```bash
magick source.jpg -strip -quality 80 public/images/portfolio/<key>.webp
magick source.jpg -strip -resize 520x -quality 80 public/images/portfolio/<key>-card.webp
magick source.jpg -strip -resize 24x -quality 50 public/images/portfolio/<key>-blur.webp
```

### Environment Variables (`.env.local`)

Client-side values must start with `VITE_` and are read with `import.meta.env` (typed in `src/env.d.ts`):

- `VITE_TURNSTILE_SITE_KEY`

Server-side secrets for the contact form API (Cloudflare secrets in production):

- `RESEND_API_KEY`
- `TURNSTILE_SECRET_KEY`

`CONTACT_EMAIL_FROM` and `CONTACT_EMAIL_TO` are plain `vars` in `wrangler.jsonc`.

## Code Style

Uses oxfmt for formatting and oxlint for linting (OXC toolchain):

- **Formatting (oxfmt)** — config in `.oxfmtrc.json`:
  - Single quotes (including JSX)
  - No semicolons
  - Trailing commas
  - 120 character line width
  - 2-space indentation
  - LF line endings
  - Import sorting (`sortImports`) and Tailwind class sorting (`sortTailwindcss`) built in

- **Linting (oxlint)** — config in `.oxlintrc.json`:
  - Plugins: eslint core, typescript, react, unicorn, oxc, import
  - Categories: correctness (error), suspicious + perf (warn)
  - `typescript/no-unused-vars` warn (`^_` ignore patterns), `typescript/no-explicit-any` warn
